Прогнозирование низкой оценки заказа в e-commerce
Описание проекта
Проект посвящён анализу факторов, связанных с негативным клиентским опытом, и построению модели машинного обучения для прогнозирования низкой оценки заказа.

Целевая переменная:

bad_review = 1 — оценка клиента 1–2 звезды;

bad_review = 0 — оценка 3–5 звёзд.

Прогноз выполняется после завершения доставки, когда фактическая информация о доставке уже известна, но клиентский отзыв ещё не оставлен.

Аналитический датасет
Финальный аналитический датасет содержит 99 441 заказ и 27 признаков до фильтрации по наличию отзыва.

Для построения ML-модели используются доставленные заказы с известной оценкой клиента.

Итоговая выборка для моделирования:

95 832 заказа

Распределение целевой переменной:

хорошая оценка: 83 521 заказа — 87,15%;

низкая оценка: 12 311 заказов — 12,85%.

Таким образом, задача характеризуется дисбалансом классов.

Были построены визуализации распределения оценок и анализа связи логистических характеристик с вероятностью низкой оценки.

Особенно выраженная связь наблюдается между задержкой доставки и негативной оценкой.

Доля низких оценок по группам задержки:

Группа	Низкие оценки
Более 14 дней раньше	9,10%
8–14 дней раньше	8,93%
1–7 дней раньше	10,28%
До 7 дней опоздания	36,13%
8–14 дней опоздания	78,20%
Более 14 дней опоздания	78,86%

При этом наблюдаемая статистическая связь не интерпретируется как доказательство причинно-следственной связи.

Machine Learning
Для прогнозирования использовались две модели:

Logistic Regression

Random Forest

Для обработки данных использовался Pipeline, включающий:

заполнение пропусков;

стандартизацию числовых признаков;

One-Hot Encoding категориальных признаков.

Разделение данных выполнено в пропорции 80/20 с использованием stratify.

Использовано 17 признаков:

number_of_items

number_of_sellers

number_of_categories

total_price

total_freight

total_order_value

avg_item_price

avg_freight_value

avg_product_weight

avg_product_photos

number_of_payments

max_installments

total_payment_value

payment_types

customer_state

delivery_time_days

delivery_delay_days

Оценка review_score не используется как входной признак модели.

Результаты моделей
Модель	Accuracy	Precision	Recall	F1-score	PR-AUC
Logistic Regression	0.7658	0.2935	0.5849	0.3908	0.4102
Random Forest, threshold = 0.55	0.8712	0.4987	0.4630	0.4802	0.4791

Поскольку целевой класс является меньшинством, особое внимание уделялось F1-score и PR-AUC.

Для Random Forest дополнительно был исследован диапазон порогов классификации от 0,20 до 0,80.

Выбран порог:

0,55

Он дал максимальный F1-score среди протестированных значений.

При этом:

Precision = 0,4987;

Recall = 0,4630;

F1-score = 0,4802;

PR-AUC = 0,4791.

Признак	Важность

delivery_time_days	24,40%

Два основных логистических признака — delivery_delay_days и delivery_time_days — вместе составляют около 55% суммарной важности признаков модели.

Это согласуется с результатами EDA, где наблюдалась выраженная связь между характеристиками доставки и долей низких оценок.

Важно отметить, что feature importance показывает информативность признаков для модели, но не доказывает причинно-следственную связь.

Бизнес-применение
Модель может использоваться для выявления заказов с повышенным риском негативной оценки после завершения доставки и до появления отзыва.

Например, прогнозируемую вероятность низкой оценки можно использовать для формирования списка заказов, которые требуют дополнительного внимания клиентского сервиса.

Потенциальный сценарий:

доставка завершена → модель оценивает риск → заказ попадает в группу повышенного риска → клиентский сервис принимает решение о дальнейшем взаимодействии.

Ограничения
Модель обучена на исторических данных.

Результаты не следует интерпретировать как причинно-следственные зависимости.

Random Forest feature importance не показывает направление влияния признака.

Качество модели оценивается на отложенной тестовой выборке.

Выбранный threshold оптимизирован по F1-score среди протестированных значений.

Модель предполагает, что фактическая информация о доставке доступна на момент прогнозирования.

Основные результаты
Проект показывает, что логистические характеристики заказа являются важными информативными признаками для прогнозирования риска низкой клиентской оценки.

Финальная Random Forest на тестовой выборке при threshold 0,55 получила:

F1-score = 0,4802

PR-AUC = 0,4791

Модель может рассматриваться как инструмент поддержки клиентского сервиса для приоритизации заказов с повышенным прогнозируемым риском негативной оценки.
